## 1. Підготовка перед захистом (обов’язково)

### 1.1. База даних
1. Запустіть MySQL (XAMPP / сервіс).
2. Відкрийте phpMyAdmin → виконайте `database.sql` **тільки на чистій копії** або після резервного копіювання.
3. Перевірте таблиці: `facility` (3 записи), `app_user` (3), `time_slot` (4), `booking` (2).
4. Зафіксуйте кількість рядків у `time_slot` = **N** (початково 4).

### 1.2. Збірка та розгортання
```bash
# Термінал 1 — сервер
cd server
mvn clean test          # має бути BUILD SUCCESS, 18 тестів
mvn clean package       # з’явиться target/sports-booking-server.war

# Скопіюйте WAR у webapps Tomcat 9.x і запустіть Tomcat
```

Перевірка API:
```
http://localhost:8080/sports-booking-server/facilities
```
Очікується JSON-масив об’єктів.

### 1.3. Клієнт
```bash
# Термінал 2 — клієнт (обов’язково з каталогу client!)
cd client
mvn javafx:run
```
Відносний шлях `sample-data/time_slots.csv` працює лише з каталогу `client`.

### 1.4. CSV
Файл: `client/sample-data/time_slots.csv`  
Заголовок: `facility_id;slot_date;start_time;end_time;price`  
8 рядків даних (facility_id = 1, 2, 3).  
Перед імпортом переконайтеся, що станції 1–3 існують.
